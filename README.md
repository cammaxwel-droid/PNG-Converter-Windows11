# PNG Converter for Windows 11

Convert batches of supported images to PNG using a desktop shortcut or the Windows right-click menu. Supports selections of 100+ pictures.

The current version is **2.2**. The ZIP contains the installer, program, bundled image converter and source code.

## Download and install

1. Download [PNG Converter v2.2](PNG_Converter_Windows11_All_Images_v2.2.zip). Click the download arrow on the ZIP’s file page.
2. Right-click the downloaded ZIP and select **Extract All…**, then **Extract**.
3. Open the extracted folder and double-click **INSTALL.cmd**.
4. Click **Yes** if Windows asks to allow changes.
5. Wait for **“PNG Converter 2.2 is ready”**, then click **OK**.

**INSTALL.cmd handles the complete setup.**

## Convert your pictures

Select your pictures, then use either method:

- **Right-click:** choose **Show more options → Convert to PNG (replace originals)**.
- **Drag and drop:** drag the selected pictures onto **Convert to PNG (batch)** on your desktop.

Wait for the progress window to say **Completed**, then click **Close**.

## What happens to your files

- PNGs are saved beside their original pictures.
- Each original is deleted only after its PNG is fully saved and verified.
- Conversion failures keep the original.
- Existing PNG files are never overwritten.
- Pictures already named `.png` are left unchanged.
- Animations and images with multiple pages or layers produce a PNG preview and keep the original.

The progress window shows errors and a summary. Click **Open log folder** to see the saved details.
